# Learning LangGraph 🚀

Welcome to my **Learning LangGraph** repository!

This repository documents my hands-on learning journey with **LangGraph, Large Language Models (LLMs), and Agentic AI**. It contains practical code examples, experiments, workflows, and projects that I build while learning how to develop AI-powered applications using Python.

My goal is to progress from understanding the fundamentals of LangGraph to building more advanced workflows, chatbots, and autonomous AI agents.

## 🎯 Learning Objectives

- Understand LangGraph fundamentals, including state, nodes, edges, and graph execution.
- Build LLM-powered workflows and experiment with prompt engineering.
- Implement prompt chaining and parallel execution patterns.
- Explore conditional routing, loops, and workflow orchestration.
- Integrate LLMs with tools and external services.
- Build conversational chatbots and AI agents.
- Explore multi-agent systems and more advanced Agentic AI applications.

## 🚀 Getting Started

1. Clone this repository or download the notebooks you want to explore.
2. Open a notebook in Google Colab or Jupyter Notebook.
3. Install the dependencies specified in the notebook or its setup instructions.
4. Configure any required API keys securely using environment variables or platform secret storage.
5. Run the notebook cells in order and experiment with the examples.

## 📈 Learning Approach

I follow a progressive, hands-on approach:

Each notebook focuses on a particular concept, workflow pattern, or project, making it easier to learn step by step.
